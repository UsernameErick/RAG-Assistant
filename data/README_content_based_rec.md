# Content-Based Steam Game Recommender

A content-based recommendation system that suggests similar Steam games using TF-IDF vectorization and cosine similarity.

## Project Overview

The recommender analyzes game genres and Steam tags to identify games with similar content.

## Technologies

* Python
* Pandas
* Scikit-learn
* TF-IDF
* Cosine Similarity
* RapidFuzz

## Features

* Content-based recommendation system
* TF-IDF vectorization of game tags
* Cosine similarity search
* Fast game title lookup using substring matching

## Workflow

1. Load Steam dataset
2. Merge genres and Steam tags
3. Generate TF-IDF vectors
4. Find requested game
5. Compute cosine similarity
6. Return the most similar games
